# PuppyLauncherCli

純コマンドラインの Minecraft ランチャー。Busbox スタイル、対話型 UI なし。

## クイックスタート

```
puppylaunchcli            # ヘルプを表示
puppylaunchcli version    # バージョンを表示
```

## 利用可能なコマンド

| コマンド | 説明 |
|----------|------|
| `help` | ヘルプを表示 |
| `version` | バージョンを表示 |
| `account local add <ユーザー>` | ローカルオフラインアカウントを追加 |
| `account local del <ユーザー>` | ローカルオフラインアカウントを削除 |

関連:
- [アカウント管理](account.md)
- [ゲームバージョン切り替え](game.md)

その他のコマンド（install、remove、update、search、game、mod、
world、resource、config）は開発中です。
